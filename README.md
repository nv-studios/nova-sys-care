# 🌌 NovaSys_Care

NovaSys_Care is an open-source, lightweight cross-platform system utility suite built natively for **Windows Batch (.bat)** and **Linux Bash (.sh)**. It provides a sleek, terminal-based care solution to clean up hidden junk, flush system-level network bottlenecks, and audit system environmental health.

---

## ✨ Features

- **🎯 Universal Navigation Engines:** Standardized navigation setups across both Windows and Linux command prompts.
- **🧹 Deep Storage Janitor:** Automatically scans and safely purges temporary file storage blocks, cached app components, and prefetch optimization logs to free up storage space.
- **⚡ Core Network Flush:** Tears down clogged internet sockets, purges old DNS resolver caches, and requests fresh router handshakes to instantly optimize ping.
- **🔍 Environment Diagnostic Audit:** Grabs data parameters from the active shell, summarizing OS architecture, system accounts, and network interfaces.
- **🎨 Premium Nova Branding:** Sleek slate-gray UI wrapped neatly with an official Nova Studios attribution tagline.

## 🚀 Quick Start Deployment Guide

### Option A: Windows Engine (`NovaSys_Care.bat`)
1. Download `NovaSys_Care.bat`.
2. Right-click the file and select **Run as Administrator** (this is strictly required to allow low-level folder sweeping and network socket resetting).
3. Use your **Up/Down Arrow Keys** to hover the selection bar over an option and press **Enter** to run it.

### Option B: Linux Engine (`NovaSys_Care.sh`)
1. Download `NovaSys_Care.sh` onto your machine (e.g., inside your ThinkPad's Downloads directory).
2. Open a native terminal tab and grant the file execution permissions:
   ```bash
   chmod +x NovaSys_Care.sh
   ```
3. Boot the console script:
   ```bash
   ./NovaSys_Care.sh
   ```
4. Enter the matching number menu choices (`1-4`) to optimize your environment.
